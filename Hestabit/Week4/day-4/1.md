Open a second terminal:

```bash

curl http://localhost:3000/api/health
```

Valid user payload:

```bash
curl -X POST http://localhost:3000/api/users \
  -H "Content-Type: application/json" \
  -d '{"firstName":"Anshul","lastName":"Garg","email":"anshul@example.com","password":"secret123","status":"active"}'
```

Invalid user payload:

```bash
curl -X POST http://localhost:3000/api/users \
  -H "Content-Type: application/json" \
  -d '{"firstName":"A","lastName":"","email":"wrong-email","password":"123"}'
```

Valid product payload:

```bash
curl -X POST http://localhost:3000/api/products \
  -H "Content-Type: application/json" \
  -d '{"name":"iPhone 15","description":"Premium smartphone","price":79999,"category":"electronics","tags":["apple","phone"],"rating":4.7,"status":"active"}'
```

Rate limiting proof:

```bash
for i in {1..105}; do curl -s -o /dev/null -w "%{http_code}\n" http://localhost:3000/api/health; done
```
